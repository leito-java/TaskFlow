# V1 — Parcours guidé de première utilisation

## Objectif

Un nouvel utilisateur doit comprendre TaskFlow sans lire une documentation externe. Le guide explique le cycle complet : organiser, créer, prioriser puis terminer.

## Parcours

1. présentation de la proposition de valeur ;
2. création d'un projet avec un nom, une icône et une couleur ;
3. création d'une tâche rattachée à ce projet ;
4. sélection dans les trois priorités du jour ;
5. finalisation de la tâche et observation de la progression.

Le guide peut être ignoré et relancé avec le bouton **Guide** de la navigation. Son achèvement est mémorisé localement par compte, sans transmettre de donnée supplémentaire au serveur.

## Choix UX

- vocabulaire orienté vers l'action ;
- une seule notion expliquée par étape ;
- navigation directe vers la page concernée ;
- progression visuelle ;
- fermeture accessible à tout moment ;
- interface adaptée aux petits écrans.

## Évolution après validation

La V2 pourra détecter réellement les actions terminées (projet créé, tâche créée, priorité choisie) et synchroniser la progression du guide entre plusieurs appareils.
